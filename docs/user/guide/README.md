# Helikodu user guide

Helikodu is an offline audio player and music library manager for Linux. It plays the music on your own computer, never connects to the internet, and lets you choose exactly which audio device it plays through.

This guide describes the current version. Helikodu is young: some menu entries and settings pages are already visible but marked as coming in a later version, and this guide leaves them out.
