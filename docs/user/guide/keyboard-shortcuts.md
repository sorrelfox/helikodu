# Keyboard shortcuts

**Ctrl+?** opens the **Keyboard shortcuts** window, which lists every shortcut; on most keyboard layouts that is **Ctrl+Shift+/**. It is also in the main menu (**Keyboard Shortcuts**, and **Help ▸ Keyboard Shortcuts**). Type in **Find an action or its keys** at the top to narrow the list.

## Playback

| Keys | Action |
|---|---|
| Space | Play or pause |
| Ctrl+Right | Next track |
| Ctrl+Left | Previous track |
| Ctrl+Shift+Right | Seek forward (by the seek step, 5 s by default) |
| Ctrl+Shift+Left | Seek back |
| Ctrl+Up | Volume up |
| Ctrl+Down | Volume down |

**Stop** and **Stop after this track** have no shortcut; they are in the **Playback** menu and in the play button's menu.

## Library and lists

| Keys | Action |
|---|---|
| Ctrl+F | Search |
| Ctrl+J | Jump to the playing track |
| Alt+Return | Track properties: opens the [tag editor](tags.md) for the selected tracks |
| Ctrl+A | Select all |
| Ctrl+Z | Undo, while a toast offers it; in a playlist, undo its last change; elsewhere, undo the last tag change |
| Ctrl+Shift+Z, Ctrl+Y | Redo the last undone change of a playlist, or elsewhere the last undone tag change |
| F2 | Rename the open playlist; in Tracks, [edit the cell](tags.md#editing-in-the-track-table) of the selected row |
| Ctrl+N | New playlist |
| Delete | Remove the selected tracks from the queue or playlist |
| Menu, Shift+F10 | Open the right-click menu of the selection |

While you type in a text field, Space, Ctrl+A and Ctrl+Z work in the field instead.

## Window

| Keys | Action |
|---|---|
| F9 | Hide or show the sidebar |
| Ctrl+M | Show or hide the menu bar (Classic window style) |
| F6 | Move the focus to the next part of the window |
| Alt+Left | Back to the previous page |
| Alt+Right | Forward |
| Ctrl+, | Settings |
| Ctrl+? | Keyboard shortcuts |
| Ctrl+Q | Quit |

Media keys (Play/Pause, Next, Previous) work through your desktop's media controls.

Changing the shortcuts comes in a later version.
