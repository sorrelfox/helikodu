# User documentation

The documentation for people who use Helikodu. It is meant to be installed with the application and opened locally from the Help menu; a copy is published on the website.

- [User guide](guide/README.md): installing, first steps, browsing and search, playing, audio output, loudness, playlists, tag editing, settings, shortcuts, the command line, files and troubleshooting.
- [FAQ](faq.md): offline by design, formats, video files, exclusive mode and PipeWire sample rates, desktop themes, settings, bug reports and privacy.

The manual pages `helikodu(1)` and `helikodu-cli(1)` are in [`data/man/`](../../data/man/) and are installed with the programs.

Describe only what the current version does. When a feature arrives, add it here in the same change.
